# Nimra Faryal — Portfolio

Next.js portfolio, exported as a static site for GitHub Pages.

- Edit all text, projects, skills and links in `src/data/portfolio.ts`. Layout lives in `src/components/`.
- Videos are in `public/videos/`, images in `public/images/`, certificates in `public/certificates/`.
- CV: `public/Nimra_Faryal_CV.tex` is the LaTeX source. Edit it on overleaf.com (or run `pdflatex`) and replace `public/Nimra_Faryal_CV.pdf` with the new PDF.
- Run locally: `npm install`, then `npm run dev` and open http://localhost:3000.
- Build: `npm install` then `npm run build`. The finished site is written to `out/`.
- Upload everything inside `out/` (including the hidden `.nojekyll` file) to the `nimrafaryal.github.io` repo.
